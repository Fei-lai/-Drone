# 10. ユウギボウシ愛媛 案件メモ

所在：**愛媛県西宇和郡伊方町 名取**（佐田岬半島）
サイト：https://yugiboushi.com/
**関係性：訪問経験あり。みかんの木オーナー制度の「オーナー」として年間使用料を支払っている。
先方はこちらのドローン測量に期待を表明している。**

## 0. これは「見込み客」ではなく「既にある案件」

| 通常の新規開拓 | ユウギボウシの場合 |
|---|---|
| まず相手を探す | ✅ **既に関係がある** |
| 現場を知らない | ✅ **訪問経験あり。現地の条件を体感で知っている** |
| ニーズを推測する | ✅ **先方から期待を表明されている** |
| 信頼を積む必要がある | ✅ **オーナーとして年間使用料を払う当事者** |

**補助金の審査で「絵に描いた餅」と見なされる最大の要因は、連携先が架空か曖昧なこと。**
実名で書ける連携先があり、しかも先方から求められている——これは申請書の説得力を決定的に変えます。
**様式2にははっきり実名と経緯を書くべきです。**

## 1. 相手の実像（公開情報より）

| 項目 | 内容 |
|---|---|
| 事業 | 四国最西端・佐田岬半島「名取」の**柑橘農家** |
| 理念 | 「人と自然が共に豊かになる未来へ」 |
| 農法 | **リジェネラティブ農業（環境再生型農業）**。農薬・化学肥料に頼らない柑橘栽培 |
| 中核の取組 | **バイオ炭による土壌炭素貯留**。剪定枝・間伐材からバイオ炭を生成し土壌に炭素を戻す**ゼロカーボン農業モデル** |
| その他 | **耕作放棄地の再生**、**段々畑の石垣（石積み）補修**、地域資源の循環モデルづくり |
| 資金調達 | READYFORでクラウドファンディングを実施（2025年12月公開） |
| **みかんの木オーナー制度** | **年間5万円（税込）／木になった柑橘はすべてオーナーのもの（不作時も30kgを最低保証）／毎月オンラインで園地の状況を報告／2〜3月に収穫体験／オーナー同士の交流会** |

**「土を再生し、土に価値をつける」** — つまり**環境価値を数値化して売ろうとしている事業者**です。
ここが決定的に重要で、**数値化＝計測＝こちらの本業**が刺さる余地が大きい。

### 現地の条件（佐田岬半島）

- 日本一細長い半島。平均300m級の山脈が主軸を走り、**平地に乏しい急峻な地形**
- 斜面に石垣を組んだ**段々畑**。石垣は土の流動化防止・排水・光の反射による保温という機能を持つ
- 運搬はモノレール（モノラック、最大45°の傾斜に対応）
- **高齢化により石垣の管理と急斜面での作業が大きな負担**

**急斜面で人が測りにくい。これはドローンの独壇場です。**

## 2. ドローン×測量が刺さる5つの論点

| # | ニーズ | 提供できること | 測量士が要るか |
|---|---|---|---|
| 1 | **バイオ炭のJ-クレジット化** | 圃場の**正確な面積確定・区画台帳の整備**、施用区画のマッピング、10年間の永続性担保のためのモニタリング基盤 | **測量士があると信頼性が段違い** |
| 2 | **石垣（石積み）の維持管理** | 補修**前後の3D比較**、はらみ出し・変状の**経年監視**。人が近づきにくい高石垣も安全に計測 | 不要（独自座標で可） |
| 3 | **耕作放棄地の再生** | 面積確定、地形・傾斜解析、日照解析、**再生優先度のマップ化**。再生の前後を数値で示せる | 面積の公的信頼性が要るなら有用 |
| 4 | **樹体・生育モニタリング** | 樹冠のサイズ・本数の把握、生育状況の可視化。無農薬・無化学肥料栽培の管理データ | 不要 |
| 5 | **作業計画・安全管理** | モノレール敷設ルートの検討、法面・危険箇所の把握 | 不要 |

### 特に狙い目は「1. J-クレジット」

J-クレジット制度には **方法論 AG-004「バイオ炭の農地施用」** があります。

- 貯留量は「施用したバイオ炭の量 × 炭素含有率 × 100年後残存率 × 44/12」で算定
- 対象は農地法第2条の**「農地」又は「採草放牧地」**における鉱質土への施用
- **永続性の担保期間は施用時点から10年間。土地転用した場合はクレジットの補填が求められる**

→ つまり **「どの区画に、どれだけ施用したか」を10年間管理し続ける必要がある。**
　 **正確な圃場図・区画台帳・面積の証拠**は、クレジット創出の土台そのものです。

**「バイオ炭を撒く人」はいても「その圃場を測量士の精度で測って10年間の台帳を作る人」はまずいない。**
ここが猷技×STUDIO．の入り込みどころです。

## 2-B. ⭐ 最大の商機は「オーナー制度そのもの」

ここが今回いちばん大きい発見です。

### 先方は毎月、遠隔のオーナーに園地の状況を報告している

オーナー制度の核は **「行けないけれど、自分の木が気になる」** という体験です。
先方はそれに応えるために**毎月オンラインで園地の状況を報告**している。
これは今おそらく写真と文章でやっているはず。

**ここにドローンが入ると、体験の質が段違いになります。**

| 今 | ドローンが入ると |
|---|---|
| 写真と文章で園地の様子を伝える | **上空からの俯瞰映像で段々畑全体を見せられる** |
| 「みかんは順調です」 | **「あなたの木はここです」と位置を特定して見せられる** |
| 収穫期に実物が届く | **1年を通して自分の木の変化を追える** |

### そのために必要なのが「樹木台帳」— つまり測量の仕事

**急斜面の段々畑で「どの木が誰の木か」を管理するのは、実はかなり大変です。**
ドローン測量で **樹木1本ごとの位置座標データベース（樹木台帳）** を作れば、
オーナー制度の運営基盤そのものになります。

そして決定的なのは——**同じ1つの測量成果が、3つの用途に同時に効く**こと。

```
        ┌─ ① オーナー制度の樹木台帳（毎月の報告・木の特定・オーナー体験の向上）
1回の    │
測量成果 ├─ ② J-クレジットの区画台帳（バイオ炭施用の面積確定・永続性10年の管理）
（点群・  │
オルソ・  └─ ③ 石垣・耕作放棄地の管理（変状監視・再生の前後比較）
座標）
```

**測量を1回やれば3つの課題が同時に片づく。** これは提案として非常に強い。

### なぜ先方に「払う理由」が生まれるか

オーナー料は**年間5万円 × オーナー数**。つまり——

> **オーナー体験の質が上がる → オーナーが増える・継続する → 先方の売上が増える**

**ドローンへの支出が先方にとって「コスト」ではなく「投資」になる。**
農家個人に高単価は出せない、という一般論の例外がここにあります。
**先方の収益モデルに直結する提案だから、予算が出る理屈が立ちます。**

### さらに：これは全国に横展開できるパッケージになる

みかんの木オーナー制度は愛媛県が県のサイトで一覧を出すほど各地にあり、
全国の果樹産地でも同様の制度が運営されています。

**「オーナー制農園向け・ドローン園地レポートパッケージ」** として商品化すれば、
ユウギボウシは1件目の実証事例になります。

> ⭐ **そしてあなた自身がオーナーです。**
> 「オーナーとして自分が欲しかったものを作る」——
> これは申請書に書ける物語として、極めて強い。
> 審査員に刺さるのは、市場調査の数字より**当事者としての実感**です。

## 3. ビジネスとしての現実（率直に）

### ✕ 課題

| 課題 | 実際のところ |
|---|---|
| **距離** | 神戸 → 伊方町名取は**約300km**。日帰りは困難、**宿泊前提** |
| **農家単体の予算** | 一般論として個人農家に高単価は出せない。**ただしオーナー制度の収益向上に直結する提案なら例外**（→ 2-B） |
| **地域の補助金が使えない** | 神戸市・兵庫県の補助金は**域内での事業**が要件になりやすい。**愛媛案件は国の制度（持続化補助金）で扱う** |

### ○ 突破口

**単発の受託ではなく「実証パートナー」として組む。** そして——

> ⭐ **補助金は「自分が取る」だけでなく、「顧客が取った補助金の外注先になる」という取り方がある。**

ユウギボウシ側が使い得る制度に、**計測パートナーとして入る**設計です。

| 相手が使える可能性のある制度 | こちらの入り方 |
|---|---|
| **みどりの食料システム戦略推進交付金** | ドローンリモートセンシングによる生育・病害虫管理は戦略に明記されている技術 |
| **みどりの食料システム法の計画認定** | 認定を受けると他の補助事業で**優先採択のポイント加算** |
| **オーガニックビレッジ**（伊方町が取り組む場合） | 市町村単位で予算がつく。自治体への営業ルートにもなる |
| **環境保全型農業直接支払交付金** | 環境負荷低減の取組の記録・可視化 |
| **J-クレジット** | クレジット創出のための計測・台帳整備を受託 |
| **クラウドファンディング** | 3Dモデル・空撮映像は**支援を集めるビジュアルとして単体で価値がある** |

**移動費を成立させる設計例**：年4回の定期計測（春・梅雨前・収穫前・剪定後）をパッケージ化し、
1回の遠征で**複数の目的（樹木台帳・石垣・生育・区画・空撮素材）をまとめて取る**。
さらに**近隣の農家・自治体にも同時に営業**して1回の遠征で複数案件を回す。

**収穫体験（2〜3月）とオーナー交流会は、既に行く予定がある機会。**
その回に計測を重ねれば、移動コストを実質的に圧縮できる（ただし次項の経費区分に注意）。

## 3-B. ⚠ 経費区分の注意（オーナーであることの副作用）

**あなたはこの農園に年間使用料を払っている顧客でもあります。** ここだけ実務上の注意が要ります。

| 論点 | 判断 |
|---|---|
| 補助対象経費の**支払先**がユウギボウシになるか | **ならない**（先方は売上先であって外注先ではない）。よって補助金で問題になりやすい「関係者との取引」には該当しない |
| **旅費を補助対象に計上する場合** | ⚠ **要注意。** 「みかんオーナーとしての私的な訪問」と見なされると否認されうる |
| オーナー料（年5万円） | **補助対象経費にはならない。** 計上しないこと |

### 対処（難しくはない）

- 訪問のたびに **打合せ記録・提案書・成果物** を残し、**事業目的の訪問であることを客観的に示す**
- **収穫体験・交流会への参加（オーナーとしての行動）と、計測・打合せ（事業としての行動）を日程上も記録上も分ける**
- 同じ遠征で両方やるなら、**旅費は事業目的の日数分だけ按分して計上する**
- 迷ったら**商工会の担当者に事前に相談**しておく。事後に指摘されるより圧倒的に楽

**やましいことは何もないので、記録さえ残せば問題ありません。** 記録を残さないことだけがリスクです。

## 4. 補助金申請での位置づけ

**メインに据えないこと。** 主力は建設・土木の3D計測です。
ユウギボウシは **「新市場開拓の実証事例」** として書くのが正解。

### 申請書での使い方（例）

> 「販路開拓の一環として、愛媛県伊方町の環境再生型農業事業者と連携し、
> 急傾斜地の段々畑におけるUAV3次元計測の実証を行う。
> 石垣の変状監視、耕作放棄地の再生管理、土壌炭素貯留に係る区画管理といった
> 新たな用途を確立し、同様の課題を抱える兵庫県内の中山間地域へ横展開する。」

**この書き方の強み：**
- ✅ 「地域課題の解決」「環境」「担い手不足」という**審査で評価される要素を全部含む**
- ✅ **実在の連携先がある**（絵に描いた餅ではない）
- ✅ **兵庫県内への横展開**を明記することで、地元での事業性にも接続できる
- ✅ 旅費は持続化補助金の対象経費になり得る（→ `03_cost_plan.md`）

## 5. 確認したいこと

| # | 質問 | 状況 |
|---|---|---|
| 1 | ユウギボウシとの関係 | ✅ **訪問経験あり・オーナー・先方から期待表明あり** |
| 2 | **先方が具体的に求めているのは何ですか？**（樹木台帳／石垣／生育／面積／オーナー向け映像／それ以外） | ⬜ 要確認。ここが提案の中心になる |
| 3 | **J-クレジットへの取り組みを、先方は既に進めていますか？** | ⬜ 要確認。進めているなら区画台帳は即戦力の実需 |
| 4 | 先方が出せる予算感と、想定する訪問頻度 | ⬜ 要確認 |
| 5 | 「中山間地の測量は言われている」の**言っている相手**はユウギボウシですか？ 他にも声をかけられている先がありますか？ | ⬜ 要確認 |

**2番が最優先です。** 先方の「期待」が具体的に何を指すかで、提案書も見積も変わります。
**次に会うとき、あるいは連絡を取るときに、この一言を聞いてください：**

> 「ドローンで何ができたら一番助かりますか？」

**その答えがそのまま様式2の中身になります。**

> ⚠ **5番も重要。** 中山間地の測量を「言っている」のが自治体や森林組合なら、
> `08_market_notes.md` の中山間地の評価を上方修正します。**発注者が誰かで単価も継続性もまるで違います。**
