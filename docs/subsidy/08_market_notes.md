# 08. 事業ドメインの検討メモ（測量業登録の要否と市場性）

作成日：2026-08-23

> **2026-08-23 更新**：「ユウギボウシ」＝**愛媛県西宇和郡伊方町名取の柑橘農園「ユウギボウシ愛媛」**と判明。

## 1. 「提携会社は必要か」への答え

**永久に必要なわけではない。「測量士」を取るまでの橋渡しにすぎない。**

### なぜ提携という話になるのか

測量法上、**「測量業」＝ 基本測量・公共測量、または「基本測量・公共測量の成果を使用して実施するその他の測量」を請け負う営業**。
これを営むには**測量業者登録**が必要で、その要件が **営業所ごとに常勤の測量士1名以上**。
**測量士補では満たさない。**

しかも「民間工事だから登録不要」ではない。
**電子基準点や公共基準点の成果を使ってRTK測位で座標を出せば、民間案件でも測量業に該当する。**
（除外されるのは「建物に関する測量その他の局地的測量」「小縮尺図の調製その他の高度の精度を必要としない測量」で政令に定めるものなど）

### 取りうる3つの道

| 案 | 内容 | 提携の要否 | 向き不向き |
|---|---|---|---|
| **案1：測量士を取る（最短ルート）** | 2027年5月の測量士試験に合格 → 測量業者登録 → 元請化 | **不要になる** | **測量士補に受かった勢いがあるうちに一気に。これが本命** |
| **案2：測量会社と提携** | 登録済み会社の下でUAVデータ取得を担当。測量士補として作業に従事 | 必要 | すぐ始められるが単価が下がり、元請になれない |
| **案3：測量に当たらない領域に特化** | 独自座標での相対計測、点検・記録用3Dモデル、農業モニタリング、災害記録 | **不要** | 許認可リスクなし。**中山間地・農業方面ならこれで十分成立する** |

### 推奨

**「案3で食いつなぎながら、案1（測量士）を最短で取る」。案2は必須ではない。**

提携が嫌なら組まなくていい。ただしその場合、**測量士を取るまでは「測量」という言葉で請け負わない**という規律が要る。
成果品を「3Dモデル」「点群データ」「土量の概算」として出す設計にすること。

## 2. 中山間地の測量：需要はあるが、単体では食えない

**率直な評価：「売上は見込めないかも」という見立ては、たぶん当たっている。**

| 論点 | 実際のところ |
|---|---|
| 需要 | **ある。** 急傾斜地・林地・農地は人が入りにくく、UAVの適地。治山事業や森林資源量把握でUAV／地上レーザ計測の活用が進んでいる |
| 発注者 | 自治体、森林組合、農業関係団体、土木業者 |
| 単価 | **低い。** 面積が小さい、予算が薄い、単発になりがち |
| 参入障壁 | LiDAR（植生下の地面を取るためのマルチリターン）がほぼ必須。**機材が高い** |
| 継続性 | 自治体案件は年度予算に紐づき、取れれば継続しやすい |

### だから、中山間地は「主力」ではなく「3つの使い道」で捉える

1. **補助金の申請書で効く。** 「中山間地域の担い手不足という地域課題に対し、UAVで応える」という筋書きは
   審査で最も評価されやすい型。**売上が小さくても、書類上の価値は大きい。**
2. **実績づくりになる。** 自治体・森林組合との取引実績は、その後の信用に直結する。
3. **閑散期を埋める。** 建設繁忙期以外に稼働を入れられる。

**結論：中山間地を主力に据えると苦しい。「建設・土木で稼ぎ、中山間地で信用と物語を作る」という配分が現実的。**

## 3. 農業ドメイン全般

具体案件（ユウギボウシ愛媛）の検討は **`10_yugiboushi.md`** を参照。ここでは市場としての一般論を整理する。

| 制度・動き | 内容 | 当社との接点 |
|---|---|---|
| **みどりの食料システム戦略**（農水省） | 2050年に有機農業を耕地面積の25%へ。**ドローン等を活用したリモートセンシングによる生育・病害虫管理技術の確立**が明記 | ◎ ドローンセンシングは戦略の中身そのもの |
| **オーガニックビレッジ**（農水省） | 有機農業を地域ぐるみで進める市町村。2022年度55市町村 → 2023年度91市町村 → **2030年200市町村**を目標に拡大中 | ○ **市町村単位で予算がつく。自治体への営業の切り口** |
| みどりの食料システム法の計画認定 | 認定を受けると他の補助事業で**優先採択のポイント加算** | ○ 中長期の布石 |
| **J-クレジット（バイオ炭の農地施用／方法論AG-004）** | 農地への炭素貯留をクレジット化。**永続性担保10年間**の管理が必要 | ◎ **区画台帳・面積確定は測量の仕事。測量士取得後の目玉になり得る** |

### 冷静に見ておくこと

- **農家個人は単価を出せない。** 相手が免税事業者なのでインボイス登録の必要性も下がる（→ `07_invoice_decision.md`）
- **狙うなら「農家」ではなく「市町村・JA・農業法人・環境価値を売る事業者」。** 予算を持っているのはそちら
- 神戸市内でも**北区（大沢・淡河）・西区は農業地帯**。**地元から始められる**のは大きな利点
- 農業モニタリングは「測量」に当たらないため測量業者登録は不要（→ 案3と整合）。
  ただし**J-クレジットの面積確定など公的信頼性が要る場面では測量士が効く**

## 4. ポートフォリオの提案

一本足で考えず、**性格の違う3本**で組むのが現実的。

```
【稼ぐ】建設・土木の3D計測（起工測量・土量計算・出来形）
        単価が高く反復性がある。※測量業登録の要否を要確認、当面は成果品の設計で対応
        → インボイス登録が要る領域

【広げる】中山間地・林業・防災
        単価は低いが、自治体との関係と補助金上の物語を作る
        → LiDARが要る。公庫融資 or 2027年度の県・市助成で

【育てる】農業・環境価値の可視化（ユウギボウシ愛媛が最初の実証先）
        政策の追い風あり。測量業登録が不要な領域から入れる
        → 相手は市町村・JA・農業法人・環境価値を売る事業者
        → J-クレジットの区画管理は測量士取得後の目玉になる
```

**補助金の申請書には、この3本立てをそのまま書くとよい。**
「一発当てる」計画より、**「地域課題に複数の角度から応える」計画のほうが審査で強い。**
