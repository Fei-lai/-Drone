## ◎ A. 小規模事業者持続化補助金〈創業型〉第4回 ← 最有力

| 項目 | 内容 |
|---|---|
| 実施 | 中小企業庁（令和7年度補正予算） |
| 補助上限 | **200万円**（インボイス特例適用で **250万円**） |
| 補助率 | **2/3** |
| 公募要領公開 | 2026年5月27日 |
| 申請受付 | **2026年11月5日（木）〜 12月15日（火）17:00** |
| 様式4（事業支援計画書）発行受付締切 | **2026年12月4日（金）** |
| 採択発表 | 2027年3月頃（第3回実績ベース） |
| 主要要件 | ①**創業後1年以内**の小規模事業者 ②**特定創業支援等事業の証明書**を認定市区町村（＝神戸市）から取得し添付 ③小規模事業者の定義（商業・サービス業は常時使用する従業員5人以下 等）を満たす |
| 参考採択率 | 第3回 **41.2%**（791／1,919者） |
| 当社の該当性 | **今年初めに商工会セミナー4回を受講済み → ②はほぼクリア見込み。①「創業後1年以内」の判定が最大の分岐点** |

**ポイント**
- 通常枠（上限50万円）と比べて枠が4倍。同じ手間なら圧倒的にこちらを狙う価値がある。
- 「受講した」＝「証明書がある」ではない。**神戸市への証明書交付申請が別途必要**（→ 最優先タスク）。
- 採択率4割強＝「出せば通る」ではない。計画書の質で決まる。

## ○ C. デジタル化・AI導入補助金2026（旧 IT導入補助金）

| 項目 | 内容 |
|---|---|
| 補助上限 | 枠により異なる（最大450万円） |
| 申請枠 | 通常枠／インボイス枠／セキュリティ対策推進枠 |
| 受付 | 2026年3月30日〜（複数締切、年度内に複数回） |
| 対象 | **事務局に登録されたITツール（ソフト・サービス）**のみ。ハードは原則対象外 |
| 当社の該当性 | 点群処理・写真測量ソフト、案件／工程管理SaaS、会計・請求ソフトなどが該当し得る。**ただし「IT導入支援事業者」が登録している製品に限られる**ため、使いたいソフトが登録されているかを先に確認する |

**使い分けの整理**：ハード（ドローン本体・LiDAR・PC）＝持続化補助金、ソフト＝デジタル化・AI導入補助金、
という切り分けにすると重複計上を避けつつ両取りできる可能性がある（同一経費の二重取りは不可）。

## ○ G. 厚生労働省系の「助成金」（人を雇う段階で）

補助金（審査あり・採択される必要あり）と違い、**要件を満たせば原則受給できる**のが助成金の強み。

| 制度 | 使いどころ |
|---|---|
| **キャリアアップ助成金** | 有期雇用のスタッフを正社員転換したとき |
| **人材開発支援助成金** | 従業員に**測量士補・ドローン国家資格などの訓練を受けさせた**とき（訓練経費＋賃金の一部） |
| **トライアル雇用助成金** | 未経験者を試行雇用するとき |

→ **測量事業を人員込みで拡大するなら、機材は補助金・人材は助成金、の二本立てが最も効率的。**
　 ただし雇用保険適用事業所であること等が前提。社会保険労務士への相談を推奨。
