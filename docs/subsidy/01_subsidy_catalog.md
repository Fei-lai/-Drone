## ✕ A. 小規模事業者持続化補助金〈創業型〉第4回 ← **対象外の見込み**

| 項目 | 内容 |
|---|---|
| 補助上限 | 200万円（インボイス特例で250万円）／補助率 2/3 |
| 申請受付 | 2026年11月5日〜12月15日（火）17:00 |
| 参考採択率 | 第3回 41.2%（791／1,919者） |
| **要件** | **「特定創業支援等事業による支援を受けた日」と「開業日（設立年月日）」の両方が、申請受付締切から起算して過去1か年の期間内にあること** |
| 第4回で対象になる開業日 | **概ね 2025年12月16日 〜 2026年12月15日** |
| **当社の判定** | 開業日 **2025年9月25日** → **約3か月早く、期間外。対象外の見込み** |

**惜しいが、開業日は動かせない。** セミナー受講日（2026年初め）は期間内だが、両方を満たす必要があるため不可。

> ⚠ **要確認**：この「過去1か年」は令和7年度補正の第3回・第4回の要件。過去の回では「過去3か年」だった時期があり、
> ネット上には古い解説（開業3年以内でOK）が残っている。**商工会または補助金事務局に開業日を伝えて必ず口頭確認すること。**
> 万一「3年以内」で通るなら上限が200万円になるため、確認する価値は極めて大きい（電話1本の話）。

## ◎ B. 小規模事業者持続化補助金〈一般型・通常枠〉第20回 ← **本命**

| 項目 | 内容 |
|---|---|
| 補助上限 | **50万円**／**＋インボイス特例 50万円 → 100万円**（賃金引上げ特例＋150万で最大250万円） |
| 補助率 | **2/3**（賃金引上げ特例に申請する赤字事業者は 3/4、かつ優先採択） |
| 申請受付 | **2026年11月5日〜12月15日（火）17:00** |
| 様式4 発行受付締切 | **2026年12月4日（金）** |
| 採択発表 | 2027年3月頃 |
| **当社の判定** | **○ 該当。上限100万円（対象経費150万円）を前提に組み立てる** |

### インボイス特例（＋50万円）— **当社は使える**

適用対象は、①2021年9月30日〜2023年9月30日の属する課税期間で一度でも免税事業者だった／免税事業者であることが見込まれる事業者、
**②2023年10月1日以降に創業した事業者** — のうち、**適格請求書発行事業者の登録が確認できた事業者**。

→ **開業 2025年9月25日は②に明確に該当。** インボイス登録さえ済んでいれば上限が **50万円 → 100万円** に倍増する。
**未登録なら今すぐ税務署に登録申請を。これが最も費用対効果の高い一手。**

### 賃金引上げ特例（＋150万円）— **現状は使えない見込み**

第20回から要件が「事業場内最低賃金＋50円」方式から
**「従業員1人あたり給与支給総額を年平均3.0%以上増加させる」方式**に変更された。
→ **従業員がいない現状では適用できない見込み。** 将来雇用したら再検討。

### 第20回のその他の変更点（申請設計に直結）

- **広報費・ウェブサイト関連費に各上限30万円（税込）**、かつ **この2費目のみでの申請は不可**
  → **既存サイト（index.html）のリニューアルだけでは申請できない。機材導入とセットにする必要がある**
- **相見積が必要な発注額の基準が「100万円超」→「50万円超（税込）」に引き下げ**
  → 機材の見積は早めに2社から取る

## ○ C. デジタル化・AI導入補助金2026（旧 IT導入補助金）

| 項目 | 内容 |
|---|---|
| 補助上限 | 枠により異なる（最大450万円） |
| 申請枠 | 通常枠／インボイス枠／セキュリティ対策推進枠 |
| 受付 | 2026年3月30日〜（複数締切、年度内に複数回） |
| 対象 | **事務局に登録されたITツール（ソフト・サービス）**のみ。ハードは原則対象外 |
| 当社の該当性 | 点群処理・写真測量ソフト、案件／工程管理SaaS、会計・請求ソフトなどが該当し得る。**ただし「IT導入支援事業者」が登録している製品に限られる**ため、使いたいソフトが登録されているかを先に確認する |

**使い分けの整理**：ハード（ドローン本体・LiDAR・PC）＝持続化補助金、ソフト＝デジタル化・AI導入補助金、
という切り分けにすると重複計上を避けつつ両取りできる可能性がある（同一経費の二重取りは不可）。

## ○ G. 厚生労働省系の「助成金」（人を雇う段階で）

補助金（審査あり・採択される必要あり）と違い、**要件を満たせば原則受給できる**のが助成金の強み。

| 制度 | 使いどころ |
|---|---|
| **キャリアアップ助成金** | 有期雇用のスタッフを正社員転換したとき |
| **人材開発支援助成金** | 従業員に**測量士・測量士補・ドローン国家資格などの訓練を受けさせた**とき（訓練経費＋賃金の一部）。※代表本人の資格取得は対象外（雇用保険被保険者が対象） |
| **トライアル雇用助成金** | 未経験者を試行雇用するとき |

→ **測量事業を人員込みで拡大するなら、機材は補助金・人材は助成金、の二本立てが最も効率的。**
　 ただし雇用保険適用事業所であること等が前提。社会保険労務士への相談を推奨。
