# 02. 事業計画ドラフト（様式2：経営計画書 兼 補助事業計画書）

> **狙う制度：小規模事業者持続化補助金〈一般型・通常枠〉第20回**（上限50万円＋インボイス特例50万円＝100万円／補助率2/3）

小規模事業者持続化補助金の申請書「様式2」の構成に沿った**叩き台**。
`【要記入】` は実データを入れる箇所。数字は必ず実績・見積に置き換えること。

> 審査で見られるのは「思い」ではなく **①誰の ②どんな課題を ③どう解決し ④いくら売上が増えるか** の4点の一貫性。
> 特に **「補助金で買うモノ」と「増える売上」が線でつながっているか**が最重要。

## 【2】顧客ニーズと市場動向

**書くべき事実（数字で語る）:**

1. **建設業の人手不足と2024年問題**
   - 建設業就業者の高齢化・減少により、現場の測量に割ける人員が減っている。
   - 従来の地上測量（TS・トータルステーション）は2〜3名×数日。ドローン写真測量／LiDARなら1名×半日〜1日で面的データが取れる。
   - → **「人を増やせない現場」の代替戦力**という需要が構造的に存在する。

2. **国土交通省のi-Construction / BIM・CIM原則適用**
   - 公共工事における3次元データ活用が標準化の方向。起工測量・出来形管理でのUAV活用が一般化している。
   - → 元請の建設会社が「3Dデータを出せる外注先」を探している。

3. **兵庫県・神戸市の地域特性**
   - 六甲山系を抱え、**急傾斜地・土砂災害警戒区域**が多い。人が入りにくい斜面の計測需要。
   - 港湾・埋立地の造成、老朽インフラ（橋梁・のり面）の点検需要。
   - 【要記入】実際に問い合わせ・相談を受けた件数、業種、内容 ← **これがあると説得力が跳ね上がる**

4. **競合状況**
   - 神戸・阪神間のドローン測量事業者：【要記入】社程度。多くは測量会社がドローンを内製化したパターン。
   - 逆に**空撮専業はいるが測量精度を出せる事業者は限られる**、という空白地帯を突く。

## 【6】書くときの注意（審査項目対応）

1. **「補助金がないとできないこと」を書く。** 既存の延長線上ではなく、新たな一歩であることを示す。
2. **経費一つひとつに「なぜ必要か」を紐づける。** 「PCを買う」ではなく「点群処理に◯時間かかり受注機会を逃しているため」。
3. **写真・図表を入れる。** 現在の機材、成果品サンプル、想定ワークフロー図。文字だけの計画書は弱い。
4. **一等無人航空機操縦士＋測量士補を前面に。** 客観的な国家資格の組み合わせは、審査員に「この人は本当に測量ができる」と伝わる最も強い材料。
   ただし**「測量業者として公共測量を受注する」とは書かない**（測量業者登録が未了のため）。→ `06_licensing_memo.md` §6 の書き分けを厳守。
5. **地域性（神戸・六甲・港湾・災害）を必ず織り込む。** 地域の課題解決は加点されやすい。
6. **数字の整合性を最後に必ず検算する。** 経費内訳の合計 ≠ 補助金申請額、は不備の典型。
