# 09. 測量士取得を前提とした3年ロードマップ

**前提：2027年5月の測量士試験に合格する。** その前提で全体を組み直す。

---

## 1. 結論：この筋書きは補助金申請と完璧に噛み合う

補助事業の実施期間（2027年）の中に、**測量士合格 → 測量士登録 → 測量業者登録 → 元請化**が丸ごと収まります。

つまり申請書にこう書ける：

> **「補助事業期間中に測量業者登録を完了し、元請としての測量受注を開始する」**

補助金審査で問われるのは「この補助金で**何が変わるのか**」。
**許認可の壁を越えて事業のステージが上がる**というのは、その答えとして最も強い型のひとつです。
機材を買って終わりの計画とは説得力が違います。

### この表から見える「絶対に落とせない日」は4つ

1. **2026年12月4日** — 様式4の発行依頼締切（商工会）
2. **2026年12月15日 17:00** — 補助金申請締切
3. **2027年1月4日〜21日** — 測量士試験の願書受付（**わずか18日間**）
4. **2027年4月の交付決定** — これより前に機材を発注したら全額自己負担

**特に3番は補助金の作業に埋もれて忘れやすい。今のうちにカレンダーに入れてください。**

## 3. 測量士試験の現実的な見立て

| 項目 | 内容 |
|---|---|
| 試験日 | **2027年5月16日（日）** |
| 願書受付 | **2027年1月4日（月）〜1月21日（木）** |
| 合格発表 | **2027年6月24日（木）9:00** |
| 受験資格 | **なし**（実務経験不要。試験合格ルートなら学歴・経験を問わず測量士に登録できる） |
| 受験手数料 | 2,850円 |
| 願書配布 | 国土地理院本院・各地方測量部、各都道府県の土木関係部局主務課、（公社）日本測量協会本部・各支部 |

### 合格率の推移 — 追い風が吹いています

| 年度 | 合格率 |
|---|---|
| 従来（〜令和5年頃） | おおむね **10%前後** |
| 令和6年（2024） | **13.0%** |
| **令和7年（2025）** | **40.2%** ← 試験制度改正（出題数の削減等）で大幅に易化 |

**測量士試験は絶対評価**（他の受験者との競争ではなく、合格基準に達すれば合格）。
制度改正以降は易化傾向にあり、**測量士補に合格した直後の今は、知識が最も残っている状態**です。
**2027年は本気で狙える年**だと思います。

> ⚠ ただし年による変動は大きい。**一発合格を前提に事業計画を組むのは危険**なので、次項のヘッジを入れます。

---

## 4. 落ちた場合のヘッジ（申請書の書き方に直結）

**補助金の事業計画は、「測量士に合格すること」を売上の前提条件にしてはいけません。**
不合格でも計画が破綻しない構成にしておくのが鉄則です。

| | 合格した場合 | 不合格だった場合 |
|---|---|---|
| 2027年秋〜 | **元請として測量を受注** | 測量に当たらない領域＋提携で継続。2028年5月に再挑戦 |
| 売上計画の土台 | ← **ここを土台にしない** | ← **こちらを土台に売上計画を組む** |

### 申請書での書き方

✅ **良い書き方**
> 「本事業では、UAVによる3次元計測サービスの提供体制を構築する。
> あわせて代表者は測量士資格の取得を進めており、取得後は測量業者登録を行い、
> 公共測量を含む元請受注へと事業領域を拡大する。」

→ **売上計画は「測量に当たらない3D計測・モニタリング」で成立させ、
　 測量士取得は「さらなる伸びしろ」として書く。**

❌ **悪い書き方**
> 「測量士資格取得後、公共測量を受注し年間○○円の売上を見込む」

→ 資格が前提の売上計画は、審査側から見ると**不確実性が高い＝減点要因**。

---

## 5. 測量業者登録の実務メモ

| 項目 | 内容 |
|---|---|
| 登録先 | **国土交通大臣**（申請は近畿地方整備局経由） |
| 中核要件 | **営業所ごとに常勤の測量士1名以上** ← 代表が測量士になれば単独で満たせる |
| 測量士の登録免許税 | **30,000円** |
| 登録の有効期間 | 5年（更新が必要） |
| 事前に確認すべきこと | 営業所の要件、財産的基礎、添付書類一式 → **近畿地方整備局 測量業係に問い合わせ** |

---

## 6. 3年後の姿

```
2026年（今）  測量士補・一等操縦士。測量に当たらない3D計測で実績づくり
              → 持続化補助金で機材整備

2027年        測量士合格 → 測量業者登録 → 元請化
              → 補助事業の成果として報告できる

2028年〜      公共測量へ参入／入札参加資格取得／人員採用
              → 省力化投資補助金・新事業進出補助金・人材開発支援助成金の射程に入る
```

**2028年に「新事業進出・ものづくり商業サービス補助金（上限4,000万円）」が現実味を帯びます。**
今回の持続化補助金は、その助走として位置づけるのが正しい。
