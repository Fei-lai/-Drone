# 03. 経費計画・積算表ひな型

## 前提

- 補助率 **2/3**（例：150万円の経費 → 補助金100万円、自己負担50万円）
- **補助金は原則「後払い」**。いったん全額を自己資金／融資で立て替え、実績報告後に入金される。
  → **資金繰り計画が必須**。日本政策金融公庫の創業融資と組み合わせるのが定石。
- **税込50万円超の発注は2社以上の相見積が必要**（第20回からの変更点）。見積取得は早めに。
- **交付決定前に発注・契約・支払いをした経費は対象外**。フライング発注は全額自己負担になる。

## 補助対象になりにくいもの（要注意）

| ✕ になりやすい経費 | 理由 |
|---|---|
| 汎用性の高いPC・タブレット・スマホ | 事業専用性が説明できないと否認されやすい（**点群処理用の高スペック機であることを明記**） |
| 自動車・バイク | 原則対象外 |
| 事務所家賃・光熱費・通信費 | 一般管理費は対象外 |
| 人件費・従業員給与 | 対象外 |
| 資格取得費（測量士補の受験料等） | 原則対象外の扱いが多い。**→ 人材開発支援助成金（厚労省）側で検討** |
| 交付決定前の発注・支払い | **全額対象外**。最頻出の失敗 |
| 中古品 | 条件が厳しい。原則新品で見積を取る |
