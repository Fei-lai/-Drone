# 03. 経費計画・積算表

**狙う制度：小規模事業者持続化補助金〈一般型・通常枠〉第20回**
補助上限 **100万円**（基本50万円＋インボイス特例50万円）／補助率 **2/3** → 補助対象経費 **150万円**まで

> **2026-08-23 改訂：M3Mは購入済みのため補助対象から除外。**
> 経費の中心を **「機体」から「処理環境と販路開拓」** に組み替えました。

---

## 0. ⭐ 機材を既に持っていることは、申請書ではむしろ強い

**「補助金がないとできないこと」が、処理環境というボトルネック1点に絞れるからです。**

> 「計測機材（DJI Mavic 3 Multispectral）は自己資金により導入済みであり、
> 既に愛媛県伊方町の現地において飛行・植生データの取得を実施している。
> しかし取得データの処理環境が追いつかず、200ha規模の広域案件を受注できる状態にない。
> 本補助事業により処理環境を整備し、既に有する計測能力を事業収益に転換する。」

**審査員から見て、これ以上に分かりやすい話はありません。**
「機材を買いたい」ではなく「**能力はあるのに、処理環境がないせいで売上にならない**」。
補助金の目的（生産性向上・販路開拓）にまっすぐ噛み合っています。

---

## 前提

- **補助金は後払い。** 全額を立て替え、実績報告後に入金。
- **税込50万円超の発注は2社以上の相見積が必須**（第20回からの変更点）。
- **交付決定前に発注・契約・支払いをした経費は全額対象外。**
- ⚠ **インボイス登録が未了だと上限50万円（対象経費75万円）に半減**（→ `07_invoice_decision.md`）
- 第20回の補助対象経費は **8種類**。**研修費は含まれない見込み**（→ §3）

---

## 1. ⭐ 経費の重心を「機材」から「販路開拓」へ移します

**保有状況が固まった結果、買うべき機材がほとんど残りませんでした。**

| 項目 | 状況 | 補助対象 |
|---|---|---|
| M3M本体 | **導入済み** | ✕ 対象外 |
| RTK | **ネットワークRTK利用可** | ✕ 基準局の購入は不要 |
| PC | **ゲーミングPC保有（メモリ32GB）** | △ メモリ増設・ストレージのみ |
| バッテリー | **4本（実飛行30分/本）** | △ 増設・現地充電環境 |

**そこで発想を変えます。持続化補助金は、そもそも「販路開拓」の補助金です。**
**機材が揃っている事業者が投資すべきなのは「売り方」のほうです。** これは筋の通った設計であり、
審査でも自然に読まれます。

### メインプラン（対象経費 約150万円 → 補助金 100万円）

| # | 費目 | 内容 | 金額(税込)目安 |
|---|---|---|---|
| 1 | 機械装置等費 | **メモリ増設（32GB → 128GB）** ※マザーボード・CPUの上限を先に確認 | 8〜15万円 |
| 2 | 機械装置等費 | **NVMe 4TB以上＋バックアップ用ストレージ／NAS**（数万枚のRAW＋中間ファイルで数TB。成果は10年管理） | 10〜15万円 |
| 3 | 機械装置等費 | **予備バッテリー増設＋ポータブル電源・車載充電環境**（遠征型の広域案件では実質必須） | 20〜25万円 |
| 4 | 広報費 | 建設会社・自治体・農業法人向け提案資料／事例集 | 25〜30万円 |
| 5 | ウェブサイト関連費 | 測量・計測サービス紹介ページ新設（成果品サンプル掲載） | 25〜30万円 |
| 6 | **委託・外注費** | ⭐ **成果品ビューワ／Web GIS の構築外注**（オーナー制農園向けレポートパッケージの中核。→ `10_yugiboushi.md` 2-B） | 20〜30万円 |
| 7 | 展示会等出展費 | 建設／測量／農業系の展示会出展 | 10〜20万円 |
| 8 | 旅費 | 実証地（伊方町名取）・展示会への旅費 | 8〜15万円 |
| | **合計** | | **約150万円** → **補助金 100万円／自己負担 50万円** |

**⭐ 6番の「成果品ビューワ／Web GIS」がこの計画の目玉です。**
撮って終わりではなく、**顧客とオーナーが自分で見られる形で届ける仕組み**。
これは新サービスの中核であり、「販路開拓」として審査でも説明しやすい経費です。

⚠ **1番のメモリ増設は「単なる部品交換・老朽設備の入れ替え」と見なされるリスクがあります。**
　 **「200ha数万枚の処理に必要な能力増強」として、処理量の根拠とセットで説明してください**（→ §4）。
　 心配なら**商工会の担当者に事前相談**を。心証を確かめてから出すのが確実です。

## 2. ⚠ 無理に150万円まで膨らませないこと

**これが今回いちばん大事な注意です。**

機材を既に持っている以上、**本当に必要なものだけを積むと150万円に届かない可能性があります。**
そのときは、**届かないまま出してください。**

| ✕ やってはいけない | ✅ 正しい |
|---|---|
| 枠を埋めるために不要なものを足す | **実態に合った額で申請する** |
| 「補助金は使い切るもの」と考える | 対象経費90万円→補助金60万円でも十分価値がある |

**水増しした経費は、採択後の実績報告で必ず苦しみます。**
使わなかった経費は補助金が減額されるだけでなく、**「計画と実績の乖離」として説明を求められます。**
最初から実態に合わせておくのが、結局いちばん楽です。

## 3. ⚠ 日本測量協会のUAV測量講習について

**受講料は補助対象外の見込みです。**

- 第20回の補助対象経費は8種類で、**研修費・受講料は含まれていない見込み**（⚠ 公募要領で要確認）
- 人材開発支援助成金（厚労省）も**雇用保険被保険者が対象**のため、**代表者本人は対象外**
- → **自己負担、または事業の必要経費として計上**

**ただし、申請書に書く価値は非常に大きい。**

> 「代表者は測量士補の資格を有し、2026年◯月に公益社団法人日本測量協会のUAV測量講習を受講、
> 『UAVを用いた公共測量マニュアル』に準拠した作業手順を習得する。
> 2027年5月の測量士試験合格を経て、測量業者登録による元請化を目指す。」

**「能力を積み上げている事業者」であることの客観的な証明**になります。
日本測量協会の講習は**測量CPD学習プログラム認定**でもあり、公共測量への布石として筋が通ります。

## 4. ⚠ ワークステーションが「汎用PC」と見なされないために

**公募要領上、汎用性の高いパソコン・タブレットは補助対象外とされる可能性があります。**
今回の中核経費なので、ここは丁寧に潰してください。

| 対策 | 具体的に |
|---|---|
| **スペック表を添付する** | メモリ128GB等、明らかに事務用ではない構成を示す |
| **専用性を明記する** | 「マルチスペクトル画像処理・点群生成専用機」として用途を限定して記載 |
| **現状の限界を数値で示す** | 「現有PCでは◯枚の処理に◯時間を要し、または完了しない」 |
| **処理量の根拠を示す** | **M3Mは1シャッターで5枚（RGB＋4バンド）を取得。200haで数万枚規模になる** |
| **見積書の品名** | 「事務用パソコン」ではなく用途が分かる記載にしてもらう |

**この4番の「5枚×200ha」が最強の説明です。** 数字が事情を全部語ってくれます。

### 参考：処理量の根拠になる数字

Metashapeのメモリ必要量の目安は**空撮写真4,000枚で512GB**とされる一方、
40Mpix 920枚ならピーク20GB程度という報告もあり、**画素数・重複度・出力設定で大きく変動**します。
大規模処理向けの構成例では**128GB〜256GB**が提案されています。

**→ 32GBが200ha規模に足りないことは、この数字で説明できます。**

⭐ ただし申請書には **「区画分割による処理設計」** もあわせて書いてください。
200haを谷筋で10〜20区画に割って処理・統合する運用なら128GBで回ります。
**やみくもに大きなPCを買う計画より、運用で解いている計画のほうが評価されます**（→ `11_natori_200ha.md` §3）。

## 6. ソフトは別制度へ（デジタル化・AI導入補助金）

Pix4Dfields（マルチスペクトル解析・NDVIに強い）、Metashape／Pix4Dmapper、QGIS などは
**持続化補助金に入れず、デジタル化・AI導入補助金2026 側で申請**すると調達総額を増やせます。

- ✅ **同一経費の二重取りは不可。**ハード＝持続化／ソフト＝デジタル化AI で切り分ける
- ⚠ 対象は**事務局に登録されたITツールのみ**。使いたいソフトが登録製品かを先に確認

## 7. 補助対象になりにくいもの

| ✕ | 理由・対処 |
|---|---|
| **既に購入済みのM3M** | **対象外。**交付決定後に発注したものだけが対象 |
| 汎用性の高いPC・タブレット | → §4 の対策で専用性を立証する |
| **研修費・講習受講料** | 8種類の経費区分に含まれない見込み（要確認） |
| **代表者本人の資格取得費**（測量士の受験料等） | 原則対象外。人材開発支援助成金も雇用保険被保険者が対象 |
| **オーナー料（ユウギボウシ 年5万円）** | 対象外。計上しないこと |
| 自動車・バイク／家賃・光熱費・通信費／人件費 | 対象外 |
| 交付決定前の発注・支払い | **全額対象外。**最頻出の失敗 |
| 中古品／申請代行業者への報酬 | 条件が厳しい／対象外 |

## 8. 資金繰りシミュレーション

| 時期 | 出来事 | 資金の動き |
|---|---|---|
| 2026/12/15 | 申請 | — |
| 2027/3頃 | 採択発表 | — |
| 2027/3〜4 | 交付申請 → **交付決定** ← **ここまで発注厳禁** | — |
| 2027/4〜 | 発注・支払い | **▲150万円（立替）** |
| 補助事業期間内 | 名取200haの実証・販路開拓 | — |
| 事業終了後 | 実績報告 → 確定検査 | — |
| 報告受理後 | **補助金入金** | **＋100万円** |
| | **実質負担** | **▲50万円** |

立替資金は**日本政策金融公庫の創業融資**と組み合わせるのが定石。
特定創業支援等事業の証明書があると**新創業融資の要件緩和・創業関連保証の枠拡大**が受けられます。
