# 03. 経費計画・積算表

**狙う制度：小規模事業者持続化補助金〈一般型・通常枠〉第20回**
補助上限 **100万円**（基本50万円＋インボイス特例50万円）／補助率 **2/3** → **補助対象経費 150万円**まで組める

---

## 前提

- **補助金は後払い。** いったん全額を自己資金／融資で立て替え、実績報告後に入金される。
- **税込50万円超の発注は2社以上の相見積が必須**（第20回からの変更点）。見積取得は早めに。
- **交付決定前に発注・契約・支払いをした経費は全額対象外。** フライング発注は最頻出の失敗。
- ⚠ **インボイス登録が未了だと上限は50万円（対象経費75万円）に半減。**まずそこを確認（→ `07_invoice_decision.md`）

---

## メインプラン：補助対象経費 150万円 → 補助金 100万円

> **2026-08-23 改訂：LiDARを外しました。**
> 連携先の目的が「土壌の復活」であり、必要なのは地盤標高ではなく**土地被覆・植生の分類**と判明。
> **マルチスペクトル（DJI M3M）が適機材**で、LiDARは第1段階では不要です（→ `11_natori_200ha.md` §0）。
> **予算の使い道がすっきりし、機材と処理環境に集中できます。**

| # | 費目 | 内容 | 金額(税込)目安 | 必要性の説明（申請書に転記する文言） |
|---|---|---|---|---|
| 1 | 機械装置等費 | **DJI Mavic 3 Multispectral（M3M）一式**（RGB 20MP＋マルチスペクトル4バンド＋太陽光センサー） | 60〜80万円 | 200haの荒廃農地の土地被覆分類とNDVIによる植生活性の把握。**太陽光センサーの日射補正により経年比較が成立する** |
| 2 | 機械装置等費 | **RTKモジュール／基準局**（センチメートル級測位） | 15〜25万円 | 標定点設置作業の削減と座標精度の担保。**急傾斜地でのGCP設置は危険かつ非現実的** |
| 3 | 機械装置等費 | ⭐ **マルチスペクトル・点群処理用ワークステーション** | 30〜45万円 | **M3Mは1シャッターで5枚を撮るため200haで数万枚規模。現有PCでは処理が完了せず受注が成立しない** |
| 4 | 機械装置等費 | 大容量ストレージ／バックアップ | 5〜10万円 | J-クレジットの永続性担保10年、交付金5年に対応するデータ保全 |
| 5 | 広報費 | 建設会社・自治体・農業法人向けサービス紹介資料の制作 | 15〜25万円 | BtoB営業ツール。**上限30万円(税込)** |
| 6 | ウェブサイト関連費 | 測量・計測サービス紹介ページ新設（成果品サンプル掲載） | 15〜25万円 | **上限30万円(税込)・単独申請不可** |
| 7 | 旅費 | 実証地（愛媛県伊方町名取）への調査・打合せ旅費 | 5〜15万円 | ⚠ **オーナーとしての私的訪問と峻別し、事業目的分のみ按分計上**（→ `10_yugiboushi.md` 3-B） |
| | **合計** | | **約150万円** | → **補助金 100万円／自己負担 50万円** |

⚠ **M3Mを既に保有している場合、それは補助対象経費になりません。**
　 これから購入する場合も、**交付決定（2027年4月頃）より前に発注したら全額自己負担**です。

### ワークステーションの仕様目安（見積を取るとき用）

多コアCPU（16コア以上）／**メモリ128GB**（64GBでは数万枚の処理で詰まる可能性が高い）／
GPU VRAM 12GB以上／NVMe 2TB以上 ＋ バックアップ用大容量ストレージ

## LiDARについて（今回は不要と判断）

**目的が「土壌の復活のための再生計画づくり」である以上、必要なのは地盤の標高ではなく
土地被覆・植生の分類です。それはマルチスペクトル（M3M）の領域であり、LiDARは要りません。**

LiDARが必要になるのは、造成・土量計算・詳細地形といった後段の工程です。
**その段階になったら、公庫融資／県・市の助成／案件が付いてから、で十分間に合います。**

## ソフトは別制度へ（デジタル化・AI導入補助金）

Pix4Dfields（マルチスペクトル解析・NDVIに強い）、Metashape／Pix4Dmapper、QGIS などは
**持続化補助金に入れず、デジタル化・AI導入補助金2026 側で申請**すると、実質的な調達総額を増やせます。

- ✅ **同一経費の二重取りは不可。費目をきれいに切り分ける**（ハード＝持続化／ソフト＝デジタル化AI）
- ⚠ 対象は**事務局に登録されたITツールのみ**。使いたいソフトが登録製品かを先に確認すること

## 補助対象になりにくいもの（要注意）

| ✕ になりやすい経費 | 理由・対処 |
|---|---|
| 汎用性の高いPC・タブレット | 事業専用性の説明が必須。**「マルチスペクトル処理用の高スペック機」であることをスペック表で示す** |
| 自動車・バイク | 原則対象外 |
| 事務所家賃・光熱費・通信費 | 一般管理費は対象外 |
| 人件費・従業員給与 | 対象外 |
| **代表者本人の資格取得費**（測量士の受験料等） | 補助金では原則対象外。人材開発支援助成金も雇用保険被保険者が対象のため代表本人は対象外 |
| **オーナー料（ユウギボウシ 年5万円）** | **補助対象にならない。計上しないこと** |
| 交付決定前の発注・支払い | **全額対象外**。最頻出の失敗 |
| 中古品 | 条件が厳しい。原則新品で見積を取る |
| 申請代行業者への報酬 | 補助対象外 |

### 立替150万円をどう用意するか

**日本政策金融公庫の創業融資と組み合わせるのが定石。**
特定創業支援等事業の証明書（受講済み → 神戸市に交付申請すれば取得可）があると、
**新創業融資の要件緩和・創業関連保証の枠拡大**が受けられます。

→ **補助金には不要になった証明書ですが、融資のために取る価値は十分あります。**
