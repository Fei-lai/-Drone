## B. 提出書類チェックリスト

### 共通
- ☐ 様式1：小規模事業者持続化補助金に係る申請書
- ☐ 様式2：経営計画書 兼 補助事業計画書①
- ☐ 様式3：補助事業計画書②（経費明細表・資金調達方法）
- ☐ 様式4：**事業支援計画書**（商工会／商工会議所が発行）← 12/4 締切
- ☐ 補助金交付申請書
- ☐ **GビズIDプライム**アカウント
- ☐ 見積書（税込50万円超は2社以上の相見積）

### 個人事業主の場合
- ☐ 直近の**確定申告書 第一表・第二表・収支内訳書**（または青色申告決算書）の写し
- ☐ 開業届の写し（創業後1年以内の証明として）

### 法人の場合
- ☐ **貸借対照表・損益計算書**（直近1期分）
- ☐ **履歴事項全部証明書**（登記簿謄本／申請日から3か月以内）

### 創業型の追加書類
- ☐ ⭐ **特定創業支援等事業による証明書**（神戸市発行）← これが無いと創業型は申請できない
- ☐ 創業日を証する書類（開業届／登記簿謄本）

### 特例を使う場合
- ☐ インボイス特例：適格請求書発行事業者の登録通知書 等
- ☐ 賃金引上げ特例：様式7（賃金引上げ表明書）、賃金台帳等
  ※第20回から要件が「給与支給総額 年平均+3.0%」方式に変更。**従業員がいない場合は使えない可能性が高い**ので要確認

## D. 相談先

| 相談先 | 何を相談するか |
|---|---|
| **管轄の商工会／商工会議所** | 様式4の発行、計画書のレビュー。**最重要パートナー**。セミナー受講済みなら既に接点があるはず |
| **こうべ産業・就労支援財団** | 特定創業支援等事業の証明書申請、創業相談 |
| **神戸市 経済観光局** | 市独自の補助制度（DX推進支援補助 等） |
| **ひょうご産業活性化センター** | 県の助成金、経営革新計画の承認 |
| **日本政策金融公庫（神戸支店）** | 立替資金の創業融資。証明書があると要件緩和あり |
| **よろず支援拠点（兵庫）** | 無料の経営相談。セカンドオピニオンに有用 |
| **認定支援機関（税理士・行政書士等）** | 申請書作成の伴走。**着手金＋成功報酬型が多く、報酬は補助対象外**なので費用対効果を要検討 |
