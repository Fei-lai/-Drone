## 1. 結論（改訂）

**活用すべき。ただし狙う制度は〈創業型〉から〈一般型・通常枠〉へ切り替えます。**

### なぜ創業型が使えないか

持続化補助金〈創業型〉第4回の要件は、
**「特定創業支援等事業の支援を受けた日」と「開業日（設立年月日）」の両方が、申請締切から過去1年以内にあること」**。

- 第4回の締切は **2026年12月15日** → 対象となる開業日は **概ね 2025年12月16日以降**
- 飛行冒険會の開業日は **2025年9月25日** → **約3か月足りない**

セミナー受講日（2026年初め）は範囲内ですが、**開業日で外れます。**惜しいですが、こればかりは動かせません。

> ⚠ ただし「1年」か「3年」かは公募回によって変遷があり、ネット上の解説記事にも古い情報（3年以内）が混在しています。
> **商工会の窓口か補助金事務局に開業日を伝えて1本電話で確定させてください。**確定するまでは一般型で準備を進めます。

### 代わりに狙うもの

**小規模事業者持続化補助金〈一般型・通常枠〉第20回**

- 補助上限 **50万円 ＋ インボイス特例 50万円 ＝ 100万円**
- 補助率 **2/3**（対象経費150万円まで使える計算）
- 日程は創業型と同じ：**申請受付 2026/11/5〜12/15 17:00、様式4の発行依頼締切 12/4**

**インボイス特例は使えます。** この特例の対象には「**2023年10月1日以降に創業した事業者**のうち、適格請求書発行事業者の登録が確認できた事業者」が含まれており、
2025年9月開業は明確にこれに該当します。**インボイス登録さえ済んでいれば上限が倍の100万円になる**ので、ここは絶対に取りこぼさないこと。

（賃金引上げ特例＝＋150万円は、第20回から「従業員1人あたり給与支給総額を年平均3.0%以上増加」方式に変わったため、
　従業員がいない現状では使えない見込みです。）

## 2. 全体戦略：100万円で足りない分をどう埋めるか

上限100万円だと測量機材一式（LiDAR含む）は賄いきれません。**制度を組み合わせて時間差で取りに行く**のが正しい戦い方です。

```
2026年12月   ① 持続化補助金〈一般型〉        …最大100万円  ← 今回の本命
             　 機材（ハード）＋販路開拓（パンフ・ウェブ・展示会）

通年         ② デジタル化・AI導入補助金       …ソフト特化
             　 点群処理・写真測量ソフト、案件管理SaaS
             　 ※ハードは①、ソフトは②に振り分けると重複計上を避けられる

並行         ③ 日本政策金融公庫 創業融資      …立替資金＋不足分
             　 特定創業支援等事業の証明書があると要件緩和・保証枠拡大
             　 補助金は後払いなので、そもそも立替資金の確保は必須

2027年4〜6月 ④ ひょうご産業活性化センター 起業家支援事業  …限度額100万円規模
             　 県・市の制度は年度当初募集。国（秋冬）とサイクルが違う
             　 ※対象者の年数要件は要確認

将来         ⑤ 新事業進出・ものづくり商業サービス補助金（上限4,000万円）
             　 測量士取得・人員確保後、本格増設の段階で
             ⑥ 人材開発支援助成金（厚労省）
             　 従業員に測量士・ドローン資格を取らせる訓練費・賃金の補助
```

## 4. 測量士補合格について

**これは計画にとって大きな前進です。** 申請書での使い方：

- ✅ **書けること**：「代表は一等無人航空機操縦士に加え、2026年5月に測量士補試験に合格し登録手続き中。
  飛行技術と測量知識の双方を有する体制を構築した」→ **実現可能性の証明として極めて強い**
- ⚠ **書けないこと**：「測量業者として登録し公共測量を受注する」
  測量業者登録は**営業所ごとに常勤の測量士1名以上**が要件で、**測量士補では満たしません**
- ✔ **正しい書き方**：段階的計画として示す
  ```
  1年目：測量会社と提携し、UAVによるデータ取得を担当（測量士補として作業に従事）
  2年目：測量士資格の取得に着手（試験合格 or 登録養成施設の課程修了）
  3年目：測量業者登録を行い、元請として公共測量にも参入
  ```
  この「段階的に許認可要件を満たしていく計画」は審査で高く評価されます。詳細は `06_licensing_memo.md`。

**2026-08-23 更新：2027年5月の測量士試験に挑戦する方針で確定。**
補助事業の実施期間（2027年）の中に「測量士合格 → 測量業者登録 → 元請化」が丸ごと収まるため、
申請書に **「補助事業期間中に測量業者登録を完了し、元請受注を開始する」** と書けます。
統合スケジュールは **`09_surveyor_roadmap.md`** を参照。
