# 補助金・助成金 活用プラン（飛行冒険會／ドローン測量事業）

作成日: 2026-08-23
対象事業者: 飛行冒険會（代表 飛来 直道／一等無人航空機操縦士）・所在 神戸市
検討テーマ: ドローンを活用した測量・3D計測事業への本格展開に、補助金／助成金を充てる

---

## 1. 結論

**活用すべき。しかも「測量をやるなら特に」使うべき。**

理由は3つ。

1. **測量は初期投資が重い事業**。RTK対応機・LiDAR・点群解析ソフト・PCワークステーション・測量士補／測量士の資格取得費など、
   自己資金だけで揃えると150〜400万円規模になる。ここは補助金が最も効く領域。
2. **今年初めに商工会の創業セミナーを4回すべて受講済み** → これはほぼ確実に
   **「特定創業支援等事業」**（経営・財務・人材育成・販路開拓の4分野を1か月以上・4回以上で学ぶ国の認定事業）に該当する。
   これを受けた人は **小規模事業者持続化補助金〈創業型〉（上限200万円／インボイス特例で250万円）** の申請資格が得られる。
   通常枠（上限50万円）の **4〜5倍** の枠が使える、極めて有利な立場にある。
3. **次回公募の日程がちょうど今から準備するのに最適**。
   申請受付 2026/11/5 〜 12/15 17:00、商工会が出す「様式4」の発行依頼締切が 12/4。
   逆算すると **9月中に事業計画の骨子、10月中に商工会へ事前相談** が理想的なペース。今が着手の適期。

## 2. まず何からやるか（優先順位つき）

| 順位 | やること | 期限目安 | 所要 |
|---|---|---|---|
| ★1 | **「特定創業支援等事業」の証明書を神戸市から取得する**（受講しただけでは証明書は出ない。別途申請が必要） | 9月中 | 申請〜交付に2〜4週間 |
| ★2 | **GビズIDプライムを取得**（電子申請の必須ID。発行に2〜3週間かかる） | 9月中 | 郵送/オンライン |
| ★3 | **開業日・事業形態の確定と確認**（創業型は「創業後1年以内」が要件。個人事業か法人かで書類が変わる） | 8月中 | 即日 |
| 4 | **事業計画の骨子を作る**（→ `02_business_plan_draft.md` に叩き台あり） | 9月末 | 本命作業 |
| 5 | **設備・経費の見積取得**（税込50万円超の発注は**2社以上の相見積が必須**に変更された） | 10月中 | 業者次第 |
| 6 | **商工会／商工会議所へ事前相談 → 様式4（事業支援計画書）の発行依頼** | 11月上旬（締切12/4） | 面談1〜2回 |
| 7 | **電子申請（Jグランツ）で提出** | 12/15 17:00厳守 | — |
| 並行 | **測量業者登録の要否を確認**（→ `06_licensing_memo.md`）。事業計画の実現可能性に直結する | 9月中 | 要調査 |

## 3. 本命と次善の組み合わせ

```
【本命】小規模事業者持続化補助金〈創業型〉第4回
        上限200万円（＋インボイス特例50万＝最大250万）／補助率2/3
        → 機材・ソフト・広報・ウェブ・展示会まで幅広く使える。測量参入と相性が最良。
        ※創業後1年以内でない場合は〈一般型・通常枠〉第20回（上限50万円）へ切替

【第2弾】デジタル化・AI導入補助金2026（旧IT導入補助金）
        点群処理／写真測量ソフト、業務管理SaaS など「ITツール」に特化。持続化と併用検討可
        （同一経費の重複計上は不可）

【将来】新事業進出・ものづくり商業サービス補助金（上限4,000万円）
        設備を伴う本格的な事業展開の段階で。今すぐは規模的にオーバースペック

【地元】神戸市中小企業DX推進支援補助制度／ひょうご産業活性化センター 起業家支援事業
        国の制度と別枠。県・市は年度当初（4月〜6月）募集が多いので2027年度4月に照準
```

詳細は `01_subsidy_catalog.md` を参照。
