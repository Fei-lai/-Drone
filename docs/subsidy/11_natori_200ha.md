# 11. 名取200haプロジェクト 技術設計メモ

案件名（仮）：**佐田岬半島・名取地区 農地再生のための広域マルチスペクトル調査**
連携先：ユウギボウシ愛媛（愛媛県西宇和郡伊方町名取）
規模：**約200ha** ／ 使用機体：**DJI Mavic 3 Multispectral（M3M）※導入済み**
**実績：M3Mで植生データの撮影経験あり。伊方町での現地撮影も実施済み。**
**体制強化：公益社団法人 日本測量協会のUAV測量講習を受講予定。**
先方の目的：**地域の復興。土壌そのものを復活させ、肥沃な大地にすること。**

---

## 0. ⚠ 前回の設計を修正します

**前回「LiDARを買う理由が証明された」と書きましたが、目的と機材が分かった今、これは的外れでした。訂正します。**

| | 前回の想定 | 実際 |
|---|---|---|
| 先方の目的 | 面積を測る | **土壌を復活させ、肥沃な大地にする（地域の復興）** |
| 必要な情報 | 地盤の標高（＝LiDARの領域） | **どこがどんな状態か、という土地被覆と植生の分類** |
| 適した機材 | LiDAR | **マルチスペクトル（＝M3Mがまさにそれ）** |

**「土を復活させる」ために最初に要るのは、地面の標高ではありません。**
**「200haのうち、どこが竹林で、どこが藪で、どこがまだ生きている園地で、どこから手を付けるべきか」——
つまり土地被覆の分類とゾーニングです。**

**それはLiDARではなく、マルチスペクトルの仕事です。M3Mの選定は正しい。**

→ **LiDARは今回の補助金計画から外して構いません。**
　 必要になるのは後段（造成・土量計算・詳細地形）の話で、少なくとも第1段階では不要です。
　 これで **予算100万円の使い道が、はるかにすっきりします。**

## 0-B. ⭐ 既に「飛べている」ことの価値

**M3Mを導入済みで、伊方町の現地でも撮影済み。これは申請書において決定的な強みです。**

| 通常の申請 | 今回 |
|---|---|
| 「機材を買って、これから始めます」 | ✅ **「機材はあり、現地でも飛ばした。あとは処理環境だけ」** |
| 現地の条件は未知 | ✅ **伊方町で実際に飛ばし、空域・電波・地形を体感で確認済み** |
| 機体の運用能力は未検証 | ✅ **植生データの取得実績あり** |

**「補助金がないとできないこと」が処理環境の1点に絞れる。**
これは審査員にとって最も理解しやすい申請の形です（→ `03_cost_plan.md` §0）。

⚠ **一方で、M3Mは既に購入済みのため補助対象経費にはなりません。**
　 経費計画は「機体」ではなく「処理環境と販路開拓」で組み直しました。

### 日本測量協会のUAV測量講習について

- 日本測量協会の講習は**測量CPD学習プログラム認定**。
  UAV関連では「UAV取得データを用いた災害地の計測と調査」「3D地形点群モデル解析基礎技術」等が開講
- 公共測量には**「UAVを用いた空中写真測量」「UAVを用いた空中写真による三次元点群測量」**の
  2つのマニュアルが整備されており、**その準拠手順を学ぶことが2027年以降の公共測量参入の前提**になる
- ⚠ **受講料は補助対象外の見込み**（研修費は8種類の経費区分に含まれない見込み・要確認）。
  **ただし申請書に「能力を積み上げている事業者」の証明として書く価値は大きい**

## 1. M3M の実力（確認済みスペック）

| 項目 | 内容 |
|---|---|
| カメラ | **20MP RGB × 1 ＋ 5MP マルチスペクトル × 4（緑・赤・レッドエッジ・近赤外）** |
| 太陽光センサー | **搭載。**日射量を記録して画像を補正 → **NDVIの精度と、経年での比較可能性が上がる** |
| RTK | RTKモジュールでセンチメートル級の測位 |
| 飛行時間 | 約43分 |
| 撮影能率（DJI公称） | **1フライトで最大200ha** |

### ⭐ 「太陽光センサー搭載」が今回の肝

**日射条件が違う日に撮っても、補正して比較できる。**
つまり **「去年の同じ場所と比べて、植生がどう変わったか」を数値で言える。**

**これは「土が肥沃になった」ことを証明する仕組みそのものです。** 後述（§4）。

## 2. ⚠ 200ha の現実 —— 公称値を鵜呑みにしないこと

**「1フライトで200ha」はDJIのカタログ値で、高高度・低解像度・平坦地が前提です。
佐田岬半島の実地では、まったくそうはいきません。**

| 制約 | 内容 |
|---|---|
| **高度制限** | 公称値は概ね高度180m前後を前提。**日本では地表150m以上の飛行に国土交通大臣の承認が必要** |
| **急峻な地形** | 平均300m級の山脈が主軸を走る半島。**対地高度を保つ地形追従飛行が必須で、効率は大きく落ちる** |
| **離発着点** | 山間部で電波が届きにくい。**複数の離発着点を設定して分割する必要がある** |
| **目視外飛行** | 200haを効率よく飛ぶなら目視外の承認が要る可能性 → **一等無人航空機操縦士が効く場面** |

### 現実的な工程の見積り方（人日ベースで積む）

| 工程 | 目安 |
|---|---|
| 事前準備（飛行計画・許可申請・地形データ取得） | 1〜2人日 |
| 移動（神戸⇔伊方町名取 約300km・往復） | 2人日 |
| 現地飛行（分割・バッテリー交換・地形追従） | **2〜4人日** |
| 内業（処理・オルソ/DSM生成・NDVI解析・分類・図化） | **5〜10人日** |
| 報告書作成・打合せ | 1〜2人日 |
| **合計** | **11〜20人日** |

**見積は「ha単価」ではなく、この工数から積んでください。**
広域案件でha単価から入ると、地形追従と移動のコストを取りこぼして赤字になります。

## 3. ⭐⭐ 200ha × 5画像 = ワークステーションの必要性が決定的に証明された

**M3Mは1回のシャッターで5枚（RGB＋4バンド）を撮ります。**

200haを実用的な解像度で撮ると、**画像枚数は容易に数万枚規模**になります。
これを処理するには、通常のPCではまったく歯が立ちません。

### 補助金の申請書にこう書けます

> 「使用機体は1回の撮影で5枚（RGB及び4バンドのマルチスペクトル）を取得するため、
> 対象面積200haの調査では画像枚数が数万枚規模となる。
> 現有のPCでは処理が完了せず、受注そのものが成立しない。
> 本補助事業により点群・マルチスペクトル処理に対応するワークステーションを整備し、
> 広域案件の受注を可能とする。」

**「あれば便利」ではなく「これがないと受注できない」。**
機材の必要性の説明として、これ以上に強い書き方はありません。

### 想定スペックの目安（見積を取るときの仕様）

| 項目 | 目安 |
|---|---|
| CPU | 多コア（16コア以上が望ましい） |
| **メモリ** | **128GB**（64GBだと数万枚の処理で詰まる可能性が高い） |
| GPU | VRAM 12GB以上（NDVI・点群処理の高速化） |
| ストレージ | NVMe 2TB以上 ＋ **バックアップ用の大容量HDD/NAS**（成果データは10年管理する前提） |

### ソフトウェアは別制度へ

- **Pix4Dfields**（マルチスペクトル解析・NDVIに強い）、Metashape / Pix4Dmapper、QGIS など
- ⚠ **これらが「デジタル化・AI導入補助金2026」の登録ITツールかを確認すること。**
  登録されていれば、**ハードは持続化補助金・ソフトはデジタル化AI補助金**で切り分けられる（→ `03_cost_plan.md`）

## 4. ⭐ 提供価値の核心 ——「土が肥沃になった」を証明する仕組み

先方の目的は**土壌の復活**です。ここから逆算すると、売るべきものが見えます。

### 単発の測量ではなく、3段構えのサービス

```
【STEP 1】現況を分類する（初年度・冬季）
   200ha全域を撮影 → 土地被覆の分類
   ・竹林化した区画 ／ 藪 ／ 草地 ／ まだ生きている園地 ／ 石垣が崩れた区画
   ・傾斜・斜面方位・日照条件（DSMから）
   ・アクセス路と作業動線
   → 成果品：ゾーニング図＋区画別の面積表＋再生の優先順位

【STEP 2】どこを調べるべきかを示す
   マルチスペクトルで植生の活性を面的に把握
   → 土壌サンプリングの代表点を科学的に選定できる
   （※土壌の肥沃度そのものはドローンでは測れない。サンプリングは必須。
      ただし「どこを掘るべきか」を決めるのがマルチスペクトルの仕事）

【STEP 3】変化を証明し続ける（年1〜2回・継続）
   同一条件で撮り続け、NDVI等の指標を経年比較
   → 「この区画は3年で植生活性が◯%向上した」と数値で言える
   → 太陽光センサーによる日射補正があるから、年をまたいだ比較が成立する
```

### STEP 3 がこの案件の本当の価値です

**「土が肥沃になった」という主張は、数値と画像がなければ誰にも証明できません。**
そして先方はそれを **4つの場面で必要としています。**

| 場面 | 何に使うか |
|---|---|
| **J-クレジット**（バイオ炭 AG-004） | 施用区画の特定と、**10年間の永続性担保のモニタリング** |
| **中山間地域等直接支払交付金**（第6期 令和7〜11年度） | 協定農用地の面積、取組の実施状況の説明 |
| **クラウドファンディング・オーナー制度** | **支援者に「変わった」ことを見せる。**空撮映像とビフォーアフターは最強の説明素材 |
| **行政・JAへの説明** | 地域プロジェクトとしての成果報告 |

> ⭐ **だから単発の受託ではなく、「年1〜2回の定期モニタリング契約」として設計してください。**
> 交付金は5年間、クレジットの永続性担保は10年間。**相手が長期で必要としている以上、
> こちらも長期で組むのが自然です。これがストック収益になります。**

## 5. 200ha ＋「地域の復興」＝ これはもう1農園の話ではない

**200haは、1つの農家が抱える面積ではありません。地域全体の規模です。**

- 荒廃農地200haの再生は、**伊方町・農業委員会・JA・愛媛県農林水産部**が関わる規模
- 中山間地域等直接支払交付金は**集落協定**が単位。農地バンクも地域単位
- **「地域の復興」という先方の言葉は、そのまま行政の政策目標と一致している**

### だから、こう位置づけを上げてください

| | 小さく書く場合 | **大きく書く場合（推奨）** |
|---|---|---|
| 顧客 | 一農家 | **地域の農地再生プロジェクト** |
| 発注者 | 個人 | **将来的に自治体・JA・協議会** |
| 単価 | 農家の自己資金 | **交付金・クレジット・地域予算** |
| 補助金での見え方 | 一社の販路開拓 | **地域課題の解決** |

**補助金の審査で最も評価されるのは「地域課題の解決」です。**
200haの荒廃農地再生の基盤データを整備する——これは文句なしにその筋書きに乗ります。

⚠ ただし **書きすぎに注意。** 現時点で確約があるのはユウギボウシとの関係だけです。
自治体・JAは**「横展開の構想」として書き、確定事実のように書かないこと。**
審査では「盛った計画」が最も嫌われます。

## 6. 飛行・法令面のチェックリスト

- ☐ **飛行許可・承認（DIPS）**：目視外飛行、150m以上の飛行、その他必要な承認の要否を確認
- ☐ **一等無人航空機操縦士＋機体認証**でカテゴリーIII飛行が可能か（機体認証の有無を確認）
- ☐ **立入管理措置**の設定（山間部・農地）
- ☐ **土地所有者の承諾**（200haとなると多数の地権者が関わる可能性）
- ☐ **電波状況の事前調査**、複数の離発着点の設定
- ☐ **保険**（賠償責任・機体）。200ha規模の受託では加入状況を先方に示せると信用になる
- ☐ 伊方町は**原子力発電所の立地自治体**。**周辺空域の飛行制限の有無を必ず事前確認すること**

## 7. 次に確認すること

| # | 確認事項 | なぜ |
|---|---|---|
| 1 | **200haの所有・権利関係**（先方の所有／借地／地域全体の面積） | 地権者の承諾範囲と、境界の論点（→ `06_licensing_memo.md` 3-B）に直結 |
| 2 | **成果品として何が欲しいか**（ゾーニング図／面積表／NDVIマップ／オルソ画像／3Dモデル） | 見積の中身が決まる |
| 3 | **いつまでに、どのくらいの頻度で** | 冬季計測の設計と、定期契約の可否 |
| 4 | **J-クレジット・交付金の申請予定はあるか** | あるなら要求される精度・記録様式が決まる |
| 5 | **伊方町・JAが既に関与しているか** | 地域プロジェクト化の可否 |
| 6 | M3Mの保有状況 | ✅ **導入済み。よって補助対象外。**代わりに処理環境と販路開拓で経費を組む |

| 7 | **RTK基準局（D-RTK 2等）／ネットワークRTK環境は保有していますか** | ⬜ **未保有なら補助対象の有力候補**（20〜25万円） |
| 8 | **予備バッテリー・充電ハブは足りますか**（200haの分割飛行に必須） | ⬜ 要確認。単価により消耗品扱いの可能性 |
| 9 | **伊方町での撮影時、空域の制限（原発周辺）で問題はありましたか** | ⬜ 一度飛ばせているなら概ねクリアと思われるが、**200ha規模では範囲が広がるため改めて確認を** |

> ⚠ **7番・8番が、今回の経費計画の空きを埋める候補です。**
> 機材が揃っている分、対象経費150万円に届かない可能性があります。
> **その場合は無理に膨らませず、実態に合った額で申請してください**（→ `03_cost_plan.md` §2）。
